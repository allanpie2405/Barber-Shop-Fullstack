# Barber-Shop-Fullstack
## Descrição 📖
Um aplicação de uma barbearia onde o cliente pode agendar um dia, hora e serviço se estiverem disponíveis e permitir o barbeiro mostrar os serviços oferecidos, gerenciar seus serviços(remover,editar,cadastrar), visualização de agendas,cancelamento de agendas e alteração de horários.
## Tecnologias 🔬
- React.js
- TailwindCSS
- Node.js
- MySQL
## Funcionalidades 💡
### Usuário 
- Realizar cadastro de perfil
- Realizar agenda de serviços por dia e hora
- Visualizar serviços
- Solicitar mudança de horário
- Notificação de mudança de horário
- Realizar cancelamento de reserva
### Barbeiro
- Cadastrar serviços
- Editar serviços(preço,nome,descrição,foto)
- Deletar serviços
- Visualizar agenda
- Realizar troca de horários
- Notificação de cancelamento de agendamento
### Possíveis funcionalidades extra ✨
- Permitir barbeiro ver serviços mais populares,menos populares e total de serviços completos no mês
